## 🚀 Featured Projects

### 🧠 StudyMate AI
An AI-powered academic assistant that lets users upload PDF documents and ask contextual questions about their content.

- Retrieval-Augmented Generation (RAG) workflow
- PDF processing and vector similarity search
- FAISS and Gemini API integration
- Multi-turn conversations grounded in uploaded documents

**Tech:** Python · FAISS · Gemini API · RAG

### 🗄️ QuartzDB
A relational database project built from scratch in Rust to explore the internal architecture of database management systems.

- SQL-like language and query parsing
- Query execution architecture
- Transaction management and indexing
- Page-based storage design

**Tech:** Rust · Database Systems · Systems Programming

### 🎮 Java 2D Game Engine
A modular 2D game engine built with Java Swing and AWT, focused on understanding the fundamentals of game-engine architecture.

- Game-loop implementation
- AABB collision detection and physics events
- State-driven entities
- Audio subsystems and tilemap serialization

**Tech:** Java · Swing · AWT · Game Development
